# motion-gimbal 项目规划

> 毕业论文：《基于 Rust 与 Python 异构架构的实时智能任务系统设计与实现》
> 截止：约 2026-11-14。同时产出英文短论文（arXiv）+ 开源仓库 + 演示视频，用于出国申请学术型硕士。

## 1. 问题

移动相机拍摄伪装或难以分辨的动物：目标外观与背景、与周围静物相近，仅靠外观难以区分。
系统要**实时**找出「相对背景独立运动」的那一个目标，排除静止与摆动类干扰，并驱动云台
（或虚拟云台）平滑地持续跟拍。

## 2. 系统架构

```text
┌────────────── Rust 核心（Tauri 宿主）──────────────┐      ┌──── Python 视觉服务 ────┐
│ 帧源：视频文件 / 摄像头 / 全幅高清序列              │      │ 检测（ONNX 推理）        │
│ 帧环共享内存 ───────────────────────────────────────┼─────▶│ 跟踪 core.mot           │
│ 任务调度（启动 / 停止 / 状态）                       │      │ 显著性 core.saliency    │
│ 控制输出：虚拟云台（取景窗）/ 真实云台               │◀─────┼ 瞄准点 core.controller  │
│ 录制与回放（逐帧 trace，可换参数复算）               │ HTTP │                         │
└──────────────────────────┬──────────────────────────┘      └─────────────────────────┘
                           │ 事件 / 状态
                    ┌──────▼──────┐
                    │ 轻量前端     │ 实时画面 + 取景窗 + 轨迹 + 指标
                    └─────────────┘
```

**分工原则**：Rust 负责实时性与资源（采集、帧传递、调度、控制输出、录制）；Python
负责算法（推理、跟踪、判据）。两侧通过共享内存传帧、HTTP 传结果。

## 5. 实验设计（以英文论文标准为准）

- **数据**：公开的「移动相机 + 伪装动物」视频数据集（候选见 `docs/literature.md`，须核实）。
  ⛔ 前期系统的数据不进入本项目实验。合成场景（`synthetic.py`）只用于单元测试。
- **主指标**：目标落在瞄准范围（取景窗）内的**时间占比**；辅以中心误差、丢失次数、控制平滑性。
- **基线**：通用多目标跟踪器 + 最显著选择；基于运动分割的伪装目标发现方法（按调研结果定）。
- **消融**：去掉背景补偿 / 排除名单挂 ID vs 挂位置 / 净位移 vs 路程 / 去掉置信闸 / 控制器限速度 vs 限加速度。
- **帧率鲁棒性**：30 / 20 / 15 / 12 / 10 / 8 Hz，均匀与非均匀帧间隔两组。
- 每组配置多次运行，报告均值与离散程度。

## 6. 已知问题与扩展

### 6.1 ⚠️ 关联闸随帧间隔线性放宽，低帧率下抢配邻居（2026-10-14 发现）

现象：合成场景 30Hz 命中率 100%，15Hz / 10Hz 降到 0%。

原因：关联闸 = 最大速度 × 帧间隔，15Hz 时为 180px，超过物体间距；一个物体漏检一帧时，
它的轨迹改配到相邻物体，背景系轨迹凭空出现位移，判据随之失效。

对照实验：闸固定为 30Hz 时的像素数后，15Hz / 10Hz 命中率回到 88~100%。

含义：「参数按时间定义」并不等于「每个参数都该随时间线性缩放」。关联闸要覆盖的是
**预测误差**，而 Kalman 预测已经包含了速度；预测误差应由预测的不确定性决定
（例如基于新息协方差的马氏距离门控，且过程噪声按 `dt` 缩放），而不是由最大速度决定。

状态：单元测试 `test_parameters_defined_in_time_survive_a_lower_frame_rate` 标为严格 xfail；
改为不确定性门控后应转绿。这一条可以直接成为论文帧率鲁棒性一节的内容。

### 6.2 背景运动只建模纯平移

相机旋转、变焦、景深视差需要单应模型（+ RANSAC）。真实云台与真实视频上必然遇到，
第 2 周评估是否升级。

### 6.3 长时间跟拍未验证

当前机制针对数秒到数十秒的序列；长时间跟拍所需的遮挡后重新找回、长期漂移修正未做，
论文中作为展望。
